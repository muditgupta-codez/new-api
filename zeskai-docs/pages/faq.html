FAQ

Quick answers to common questions.

Is Zeskai OpenAI-compatible?

Yes. Point any OpenAI SDK or tool at https://zeskai.com/v1 with your Zeskai key and it works.

How do I get an API key?

Sign in at zeskai.com → Console → Token → Add Token. See Authentication.

How am I billed?

Pay-as-you-go. You top up your balance and each request deducts based on token usage × the model's price ratio. No subscription.

Which models are available?

25+ models across DeepSeek, GLM, GPT, Grok, Kimi, MiniMax, Mimo and Qwen. Full list at Models. New models are added automatically.

Can I use Zeskai in my own app?

Yes — it's a standard REST API. See Examples for Python, Node.js and curl.

Why did my request fail with 402?

Your balance is too low. Top up from the dashboard and retry. See Errors.

What does "Endpoint is unavailable" mean?

The upstream model provider is temporarily down. Retry in a minute, or use a different model.

Is my API key safe?

Keys are stored encrypted and shown only once at creation. Rotate them regularly and never share them. See Authentication.

How do I get support?

Contact us through the links on zeskai.com — include your request ID or the exact error message for fastest help.

Can I cancel anytime?

There's no lock-in. Spend down your balance or stop using the API — no cancellation fees.
