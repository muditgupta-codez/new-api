Authentication

All requests are authenticated with your Zeskai API key as a Bearer token.

Getting a key

  1. Sign in at zeskai.com
  2. Open the Console → Token page
  3. Click Add Token, pick a name and expiry
  4. Copy the key immediately — it is shown only once

Sending the key

Add it as an Authorization header:

Authorization: Bearer sk-zeskai-...

Or in an OpenAI client, pass it as api_key:

client = OpenAI(
    api_key="sk-zeskai-...",
    base_url="https://zeskai.com/v1",
)

Key safety

  • Keys are charged to your balance — treat them like money
  • Rotate keys regularly from the Token page
  • Never commit keys to source control or share them in public chats
  • Set an expiry on long-lived keys

Quota & balance

Each request deducts from your account balance based on token usage and the model's price ratio. You can top up from the dashboard. If your balance runs out, requests fail with insufficient_quota (402) until you top up.

Note: Zeskai bills in USD. One USD of balance ≈ 1 USD of model usage at the published ratios.
