Quickstart

Make your first API call in under two minutes.

1. Get an API key

Sign in at zeskai.com, open the Console, and create a token. Copy it — you'll only see it once.

2. Make your first request

Everything goes through https://zeskai.com/v1 with your key as a Bearer token.

curl https://zeskai.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-flash",
    "messages": [
      {"role": "user", "content": "Say hello in 5 words"}
    ]
  }'

You should get a response with the model's reply:

{
  "id": "chatcmpl-...",
  "model": "deepseek-v4-flash",
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": "Hello! How can I help?"
      }
    }
  ],
  "usage": {
    "prompt_tokens": 12,
    "completion_tokens": 8,
    "total_tokens": 20
  }
}

3. Pick a model

Swap deepseek-v4-flash for any model in the catalog. Prices vary per model — see pricing.

Heads up: use a cheap model like deepseek-v4-flash (ratio 0.07) while testing. Flagship models like qwen3.8-max cost ~18x more per token.

4. Use it anywhere

Zeskai is OpenAI-compatible, so it drops into any existing OpenAI client by changing the base URL and key:

# Python (openai SDK)
from openai import OpenAI
client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://zeskai.com/v1",
)
resp = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(resp.choices[0].message.content)
