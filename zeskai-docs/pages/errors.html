Errors & Limits

Common error codes and what they mean.

Error format

Errors return the OpenAI-style JSON shape:

{
  "error": {
    "message": "Insufficient Quota",
    "type": "insufficient_quota",
    "code": 402
  }
}

HTTP status codes

CodeMeaningFix

Rate limits

  • Requests are metered per account; sustained bursts may be throttled with 429
  • Use exponential backoff when retrying (e.g. 1s → 2s → 4s)
  • Prefer streaming for long outputs to stay within limits

Retry policy

Transient errors (429, 500, 503) usually resolve in seconds. Retry with backoff. If a model stays unavailable, switch to another model from the catalog — most have close equivalents.
