API Reference

The Zeskai API is OpenAI-compatible. This page documents the endpoints and key parameters.

Base URL

https://zeskai.com/v1

Endpoints

EndpointMethodDescription
/v1/chat/completionsPOSTChat completions (all models)
/v1/responsesPOSTResponses API
/v1/modelsGETList available models

POST /v1/chat/completions

Standard OpenAI chat request:

{
  "model": "deepseek-v4-flash",
  "messages": [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Explain quantum computing in one sentence."}
  ],
  "temperature": 0.7,
  "max_tokens": 500,
  "stream": false
}

Key parameters

ParameterTypeDescription
modelstringRequired. Model name from the catalog
messagesarrayRequired. Chat messages with role and content
temperaturenumberSampling temperature (0–2). Default varies by model
max_tokensintegerMax output tokens
streambooleanStream tokens as SSE (default false)
top_pnumberNucleus sampling

Streaming

Set "stream": true to receive server-sent events. Each chunk has the standard OpenAI delta format:

data: {"choices":[{"delta":{"content":"Hello"}}]}

data: [DONE]

POST /v1/responses

OpenAI Responses API format (for compatible models):

{
  "model": "gpt-5.6-luna",
  "input": "Tell me a fun fact"
}
