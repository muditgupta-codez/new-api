Pricing

Pay-as-you-go. Every model has a price ratio; your bill is token usage × ratio.

How billing works

Zeskai meters usage in tokens and converts to USD using each model's ratios:

cost = (input_tokens × price_ratio
        + output_tokens × price_ratio × completion_ratio)
       × unit_price
  • Price ratio — base multiplier for the model (see table below)
  • Completion ratio — output tokens cost this many × more than input
  • Unit price — the platform's base rate per token unit
